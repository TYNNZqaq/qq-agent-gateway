# QQ Agent Gateway

通过自己的 QQ 机器人，接收本机 Codex 会话通知、回答原生问题、继续或取消已有任务，并管理 QQ 聊天、项目工作和文件交付。提供 Windows 本机管理台，账号、机器人和数据由使用者自行配置。

首次登录、登记机器人并完成必要授权后，向导自动准备业务数据和本人配对；配对成功后自动配置通知、Q 问答、原会话控制并连接机器人。此时先提供原生会话连接；QQ 独立聊天和新任务生成仍需本人主动完成模型自检。已配置的机器人也会在 Codex 桌面启动时自动连接，已有在线服务直接复用。

## 功能

| 功能 | 使用方式与条件 |
| --- | --- |
| 本机接入管理 | 登录本项目独立的 ChatGPT 账号，管理 QQ 凭据、绑定、配对及项目授权 |
| 桌面通知 | 将已同意范围内的 Codex 回合完成、失败、中断与问题发送给已配对本人 |
| 原会话控制 | 在 QQ 选择已有任务，发送指导、继续同一对话，或取消所引用的原回合；需原窗口可连接 |
| Q 原卡片回答 | 按通知回复 `回答 Q编号：答案`；仅对能核对原请求的表单开放回写 |
| QQ 聊天与工作 | 人设、来源记忆、任务列表、状态、结果和继续任务；独立模型执行需通过当前环境自检 |
| 图片与文件 | 接收附件、关联任务、分段结果通知与文件交付；按项目授权和发送状态执行 |
| 启动自动连接 | Windows 当前用户登录后运行监听器，Codex 主窗口出现时复用或启动本实例 QQ 服务 |

当前接入对象是 Codex。浏览器和 Computer Use 的独立应用访问授权仍在本机处理；DSH、Gemini 暂未接入。

## 开始使用

需要 Windows、独立安装并可从 `PATH` 找到的 **Node.js 24 或更新版本**、兼容的官方 Codex CLI，以及需要连接原生会话时的 Codex 桌面。还需自己的 QQ 开放平台机器人及其 AppID/AppSecret。Codex、Node.js 和 QQ 平台账户不随本项目提供。

本版本适配 CLI `0.167.0` 和 `0.167.0-alpha.3.2` 的账户连接，已在隔离目录核对只读协议。可用 `npm install -g @openai/codex@0.167.0` 安装固定版，再在新终端运行 `codex --version`。这两个 0.167 版本目前可用于账户连接和原生会话模式，**独立模型生成仍未开放**；其他受支持版本也须通过当前环境的实际验证。

1. 从 [Releases](https://github.com/TYNNZqaq/qq-agent-gateway/releases) 下载 Windows 程序包，解压到**非系统盘的独立目录**，双击 **安装.cmd**。程序包已含锁定的公共 npm 依赖。若下载源码，在同样的独立目录运行 `npm ci` 后再安装。
2. 在本机管理台登记 QQ 机器人和 Codex 实例，建立绑定，在「接入 → Codex」完成官方页面登录、选择模型并填写自己的 QQ 凭据。桌面已有登录不代替本项目独立登录。
3. 阅读并确认数据使用范围，包括本机原生会话通知、问题和控制。管理台随后自动初始化业务并发起本人配对，在当前窗口展示配对码；此阶段不要求先授予独立工作目录权限。
4. 在自己的机器人私聊中发送该配对码。配对成功后自动完成原生功能配置并连接；若提示桌面尚未初始化，先打开 Codex 桌面，再刷新接入状态。
5. 发送 **主菜单**，按编号使用「Codex 工作」中的已有任务、问题、状态和文件入口。需要 QQ 独立聊天或新建任务时，先在本机正常停止服务、授权具体工作项目，再主动运行模型实际自检；通过后自动衔接完整执行。

管理台仅监听 `127.0.0.1`，默认端口为 `17391`；端口占用时选择可用端口，以启动结果为准。程序、用户数据分开保存，数据目录不能位于系统卷或程序目录。详见 [完整用户指南](docs/USER-GUIDE.md)。

## 连接与能力状态

“QQ 在线”“原窗口控制已连接”和“独立模型执行已验证”分别显示。原生连接沿用桌面原对话的模型和权限；自检未通过时，网关不会自行开启独立模型生成，也不会静默换模型或改用 API Key。

原生控制依赖当前桌面的本机协议和原窗口状态；协议不兼容、来源不符或提交结果不确定时暂停对应操作。普通工具审批、Q 问答和浏览器宿主授权各自核对，回答一个问题不代表批准其他操作。原生工具审批钩子还需用户在本机审阅和信任。

当前原生控制与 Q 回写已有代码和离线验证、真实只读连接验证；本次发布未以真人 QQ 写入、客户端冷启动或全新机器安装作为全功能验收。请以管理台的具体就绪状态使用功能。

## 数据与停止方式

程序包和开源仓库不含使用者的账号、QQ 凭据、配对、消息、任务或执行证明。QQ 凭据在本机加密，项目账号目录独立保存；正常使用会按你确认的范围向 QQ/OpenAI 发送必要内容。分享诊断前先在管理台预览脱敏结果。

「停止机器人服务」停止业务服务；**停止管理界面.cmd** 只停止管理台。关闭浏览器页不会停止服务。关闭启动监听器、查看数据目录及升级备份的方法见 [用户指南](docs/USER-GUIDE.md#启动自动连接与关闭)。
